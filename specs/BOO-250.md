# BOO-250 — README „What's new"-Block entschlacken

## Summary

Der „What's new"-Absatz der README (DE+EN) war eine dichte Text-Wand — jede Welle/Version seit v0.6 in *einem* ~2000-Zeichen-Absatz. Eingedampft auf eine scannbare Form: Lead + 4 Highlight-Bullets der grossen Meilensteine + Verweis auf `docs/releases/_index.md` für die Vollhistorie. B2 aus BOO-249 (dort bewusst ausgeklammert). Reine README-Prosa. Quelle: Operator-Befund 2026-06-23.

## Why

Die Wand war kaum scannbar und duplizierte die chronologische Wellen-Historie, die ohnehin in `docs/releases/_index.md` als SSoT lebt. Ein Einstiegs-Dokument soll die grossen Linien zeigen, nicht jede Welle.

## What

- **DE+EN:** „What's new" / „Was ist neu" auf Lead + **4 Bullets** verdichtet:
  - v0.11.0 (Sprint 3) — Build-vs-Buy-Pivot, `/sprint-run` auf native `/goal`-Engine.
  - v0.12.0 (Sprint 5) — Claude-Code-first (A/B/C-Schalter + `/implement`-Migration).
  - v0.13.0 (Sprint 6) — Worker-Equivalent in Status-Line, backlog-Write-back, ADR-5, Infra-Layer-Onboarding.
  - Früher (v0.7.x) — Enterprise-Readiness & EU-AI-Act-Opt-in, Compliance-Mechanik, Artefakt-/Freigabe-Landkarte, DE/EN-Parität.
  - Post-Release: Doku-Drift-Checker + `compliance_doc_gate` (BOO-229).
- Verweis auf `docs/releases/_index.md` für die vollständige Chronologie.

## Constraints

- **Anti-Fabrikation:** nur bestehende, belegte Fakten verdichtet — nichts erfunden, keine neuen Versionen/Wellen. Die ausführliche Wellen-Historie (AW/AX/BA/BB …) bleibt in `docs/releases/_index.md` erhalten — nichts geht verloren, nur die Dopplung in der README entfällt.
- Reine README-Prosa; `docs_drift_check.py` bricht nicht an Prosa.
- DE/EN paritätisch.

## Acceptance Criteria

1. „What's new" DE+EN deutlich kürzer + scannbar (Lead + wenige Highlight-Bullets + Verweis auf `docs/releases`).
2. Keine erfundenen Fakten; Vollhistorie weiter in `docs/releases/_index.md`.
3. `docs_drift_check.py` grün (rc=0), DE/EN paritätisch.

## Result

Umgesetzt in PR (Folge zu BOO-249, B2). README DE+EN: „What's new" von der Text-Wand auf Lead + 4 Bullets + Index-Verweis eingedampft. docs-drift grün.
