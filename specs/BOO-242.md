# BOO-242 — spike/docs: Firmenkontext-Layer auf der Developer-VPS

## Summary

Spike: entscheiden, ob neben dem Projektverzeichnis ein „Company-SecondBrain" auf der Dev-VPS sinnvoll ist. Ergebnis als ADR dokumentiert: **ja, aber lean** — als referenzierte Ebene der bestehenden globalen `CLAUDE.md`, kein paralleler Mechanismus, kein Voll-Vault-Klon. Reine Doku/Entscheidung; Umsetzung = Folge-Story. Sprint 8.

## Why

Dev-VPS syncen Projektwissen (BOO-138/139), aber der firmenweite Kontext (Zweck/Ziele/Werte) fehlt — Claude/Codex weiss projektübergreifend nicht, in welchem Unternehmen es arbeitet. Operator-Sorge: keine zwei losen Mechanismen (SecondBrain vs. Projektverzeichnisse).

## What

- ADR `docs/domain/adrs/company-context-layer.md` (+ `.en.md`), Status „vorgeschlagen" (Festschreibung Operator).
- Kern: Firmenkontext = referenzierte Ebene der globalen `CLAUDE.md`/`AGENTS.md` (die bereits Machine context + PROJECTS_ROOT + Projekt-Registry + Journaling hält) → eine Landkarte, nicht zwei.
- Scope = Firma/Zweck/Ziele/Werte; Branding ausgeschlossen (Projektebene); Sensibles bleibt im Master-Vault (Anhang Q).
- Form: kleines `company-context.md` (inline 1 VPS / kleines Repo Multi-VPS), kein Voll-Vault-Klon. Surfacing opt-in via Post-Install-Checkliste.
- In `docs/INDEX.md` + `.en.md` registriert.

## Constraints

- Reine Doku/Entscheidung, kein Code.
- Gegen verifizierten Framework-Stand gegroundet (globale CLAUDE.md = Machine context + PROJECTS_ROOT + Registry; BOO-138/139), keine erfundenen Mechanismen.
- DE/EN paritätisch; docs-drift grün.

## Acceptance Criteria

1. [x] Entscheidung dokumentiert: referenzierte Ebene der globalen CLAUDE.md (eine Landkarte), Scope Firma/Zweck/Ziele/Werte, Branding ausgeschlossen
2. [x] Form geklärt: `company-context.md` inline (1 VPS) vs. kleines Repo (Multi-VPS), kein Voll-Vault-Klon
3. [x] Privacy-/Sensibilitäts-Abgrenzung (Sensibles bleibt im Master-Vault, Anhang Q)
4. [ ] Folge-Story für die Umsetzung — nach Operator-Festschreibung

## Result

ADR (Vorschlag) umgesetzt in Sprint 8, Branch `feat/sprint8-enablement-docs`. Festschreibung + Folge-Story offen (Operator).
