# BOO-239 — Unabhängiger Code-Reviewer via Codex (Opt-in-Governance-Layer)

## Summary
Produktisiert einen **unabhängigen** Code-Reviewer (Codex — bewusst ein *anderer* Anbieter als der Autor Claude) als **Opt-in-Layer**: Zwei-Tier-Runbook (GitHub-nativ / Azure-EU souverän), AGENTS.md-Review-Guidelines, Findings-Flow (Report-only → Story → Pipeline), 2 Daten-Flow-Sketches. **Kein** Gate, kein Auto-Fix, kein MCP-Server, kein stehender Agent. Reine Doku/Vertrag (Build-vs-Buy, ADR-1).

## Why
Bisher reviewt nur der Autor (Claude) seinen eigenen Code (`/architecture-review`) — Interessenkonflikt (gleiche blinde Flecken, gleiche Modell-Familie). Die deterministischen Gates (Semgrep/Sonar/Coverage) fangen Regelverstöße, aber nicht Design/Handwerk/Edge-Cases. Ein unabhängiger zweiter Pass von einem *anderen* Anbieter (Vier-Augen auf Werkzeug-Ebene, BOO-150/BOO-227) schließt die Lücke. Codex ändert nie Code — die Behebung bleibt in der Governance-Pipeline.
