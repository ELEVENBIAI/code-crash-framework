# BOO-244 — README: Code-Crash-/Schrader-Bezug klarer erklären

## Summary

Der Bezug zwischen INTENTRON, Matthias Schraders Buch »Code Crash« und der Namensherkunft (INTENT + -TRON) war in der README über vier Stellen verstreut (Intro-Einzeiler, Name-Absatz, Methoden-Abschnitt, Footer-Disclaimer) und setzte Vorwissen voraus. Diese Story bündelt den narrativen Bogen **Name ↔ Buch ↔ Methode ↔ Inspiration** an *einer* gut auffindbaren Stelle (DE+EN) und verlinkt die verstreuten Erwähnungen dorthin, statt zu duplizieren. Reine Doku, kein Verhaltens-Change. Quelle: Operator-Befund 2026-06-21.

## Why

Ein Leser verstand nicht auf einen Blick, **was »Code Crash« ist, wer Schrader ist und wie INTENTRON daraus folgt** — die Information lag verteilt vor. Ein Framework, das »Intent vor Spec« predigt, sollte seine eigene Herkunfts-Erzählung an einer Stelle sauber führen. Gleichzeitig muss der Trademark-/Unabhängigkeits-Disclaimer (eigenständiges Produkt, keine Geschäftsbeziehung, Methodik angelehnt) gewahrt bleiben — ohne erfundene Zitate oder Endorsements.

## What

- **Kanonischer Herkunfts-Abschnitt (DE+EN):** der bestehende Abschnitt »Why the method comes from Code Crash« / »Warum die Methode aus Code Crash kommt« wurde zu **»Where INTENTRON comes from — the book ‚Code Crash' by Matthias Schrader«** / **»Woher INTENTRON kommt — das Buch »Code Crash« von Matthias Schrader«** umgebaut. Er enthält jetzt alle drei Elemente an einer Stelle: (1) *Was »Code Crash« ist* (Buch von Matthias Schrader + Kern-These), (2) *Wie INTENTRON daraus folgt* (Übersetzung in ein lauffähiges Betriebssystem), (3) *Woher der Name kommt* (INTENT + -TRON). Stabiler HTML-Anker `#origin` (EN) / `#herkunft` (DE).
- **Konsolidierung statt Dopplung:** Der Name-Absatz im Intro (DE+EN) wurde auf einen kurzen Hook + Vorwärts-Link zum kanonischen Abschnitt gekürzt — die ausführliche Name-/Spec-Erklärung lebt nur noch an einer Stelle.
- **Auffindbarkeit:** Je eine Zeile in den Tabellen »Where to Start« / »Wo anfangen?« verweist auf den kanonischen Abschnitt.
- **Disclaimer:** Eine knappe, faktische Unabhängigkeits-Notiz (Verweis auf `NOTICE` + Footer) im kanonischen Abschnitt; Footer-Disclaimer und `NOTICE` unverändert.
- **Namensschreibung:** »Matthias Schrader« repo-weit gegen Tippfehler-Varianten (Schräder/Schraeder/Schroeder/Mathias) geprüft — keine Fehler gefunden, alle Vorkommen korrekt.

## Constraints

- Reine README-Prosa, kein Code-/Verhaltens-Change; `docs_drift_check.py` bricht nicht an Prosa.
- Anti-Fabrikation: kein erfundenes Erscheinungsjahr, kein Verlagsname, keine Zitate/Endorsements — nur die durch `NOTICE` belegten Fakten (Buchtitel + Autor + Unabhängigkeit).
- Trademark-/Unabhängigkeits-Disclaimer wortgleich zur `NOTICE`-Aussage, keine Überzeichnung einer Beziehung.
- DE/EN paritätisch; bestehende Anker/Links nicht gebrochen (kein Dokument verlinkte die alten Abschnitts-Anker).

## Acceptance Criteria

1. README erklärt klar an **einer** Stelle (DE+EN): was »Code Crash« (Buch/Schrader) ist + wie INTENTRON daraus folgt + Namensherkunft.
2. Bestehende Erwähnungen konsolidiert/verlinkt, keine Dopplung; Disclaimer intakt; »Matthias Schrader« korrekt geschrieben.
3. `docs_drift_check.py` grün (rc=0).
